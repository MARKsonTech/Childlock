# Childlock 🛡️

A safe, secure, and easy-to-use interface designed to block harmful websites and protect children online.

## 🌟 Features

- **Simple & Intuitive UI:** Easy for parents to set up and manage without technical expertise.
- **Robust Blocking Mechanism:** Fast and secure filtering to keep harmful content away.
- **Custom Blocklists:** Add specific websites or categories to tailor the restrictions for your family.
- **Secure Access:** Password-protected configuration panel to prevent unauthorized modifications or bypasses.
- **Lightweight & Fast:** Runs efficiently in the background without affecting device performance.

## 🚀 Getting Started

### Prerequisites

Before installing Childlock, make sure you have the following requirements installed:
- Windows 7 / 8 / 8.1 / 10 /11

## 🛠️ Usage

1. Open the program added to the desktop called `Child Lock`
2. Don't forget to lock down your `enycript` folder and `hosts_blocker_data.json` file found in the installation folder found in `C:/Programfiles/markson/childlock`
3. Log in using your own set password.
4. Use the dashboard to:
   - Toggle the child lock system on/off.
   - Add/remove URLs from the blacklist.
   - View recent access attempts.
